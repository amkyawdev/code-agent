# Knowledge Web Skill - Web Research & Information Gathering

## Overview
This skill provides comprehensive web research and information gathering capabilities.

## Purpose

The Knowledge Web skill enables:
- Finding and synthesizing information from various sources
- Researching technical topics and documentation
- Gathering solutions to common problems
- Consolidating findings from multiple sources

## Capabilities

### 1. Search & Research
- **Documentation Search**: Find official documentation and guides
- **Problem Solving**: Search for solutions to known issues
- **Technical Specifications**: Gather detailed technical information
- **Best Practices**: Research industry best practices and patterns

### 2. Information Synthesis
- **Consolidation**: Combine findings from multiple sources
- **Pattern Identification**: Identify common patterns and solutions
- **Comparison**: Compare different approaches and tools
- **Recommendations**: Provide actionable recommendations

### 3. Technical Research
- **API Documentation**: Find and explain API references
- **Code Examples**: Gather working code samples
- **Tool Comparisons**: Compare development tools and frameworks
- **Version Information**: Research version compatibility

## Usage Guidelines

### Starting Research
1. Define a clear research question or objective
2. Specify the depth of research needed
3. Identify any constraints or preferences
4. Request specific output formats

### Research Examples

**Documentation Research**:
```
Find the official documentation for [topic].
I need to understand [specific aspect].
```

**Problem Solving**:
```
Search for solutions to this issue: [description]
Include error messages and context: [details]
```

**Technical Comparison**:
```
Compare [option A] vs [option B] for [use case].
Focus on: [specific criteria]
```

## Best Practices

1. **Clear Objectives**: Start with a well-defined research question
2. **Relevant Context**: Provide background information
3. **Specific Criteria**: Define what success looks like
4. **Format Preferences**: Specify how you want results presented

## Output Formats

### Summary Format
```markdown
## Summary
[Brief overview of findings]

## Key Points
- [Point 1]
- [Point 2]

## Recommendations
- [Recommendation 1]

## Sources
- [Source 1]
- [Source 2]
```

### Detailed Report Format
```markdown
## Research Topic
[Title]

## Findings
[Detailed findings]

## Analysis
[Analysis and interpretation]

## Conclusions
[Main conclusions]

## References
[All sources cited]
```

## Tips for Effective Research

1. **Be Specific**: Narrow down the topic for more focused results
2. **Provide Context**: Help understand your specific situation
3. **Iterate**: Start broad, then refine based on initial findings
4. **Cross-verify**: Compare information from multiple sources

## Progressive Disclosure

### Level 1: Quick Answer (5 min)
- Direct answer to simple question
- Single source
- 1-2 paragraphs

### Level 2: Standard Research (15 min)
- Multiple sources
- Comparison if applicable
- Summary and recommendations

### Level 3: Deep Research (30+ min)
- Extensive sources
- Detailed analysis
- Comparisons and analysis
- Future outlook
- Comprehensive references
