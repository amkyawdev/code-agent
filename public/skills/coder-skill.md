# Coder Skill - Build & Fix Only

## Rules
1. **DO NOT TEST** - Only build and fix code
2. **Read skill files** - Load instructions from available skills
3. **Write actual code** - Generate working code, not explanations
4. **Use CLI commands** - Run terminal commands for build/fix operations
5. **Auto-fix errors** - If build fails, fix automatically
6. **Show output** - Display all commands and results

## Workflow

### 1. Analyze Task
- Read user requirements
- Check available skill files
- Plan implementation approach

### 2. Write Code
- Generate clean, working code
- Include proper error handling
- Follow best practices for the language

### 3. Build & Fix
- Run build commands (npm, git, etc.)
- If errors occur, fix immediately
- Repeat until successful

### 4. Output Format
```
## Task
(What was requested)

## Commands
(List terminal commands run)

## Code
(Code blocks written)

## Result
(Build success or errors fixed)
```

## Supported Operations
- Write new code (JS, TS, Python, etc.)
- Fix syntax errors
- Fix import/dependency errors
- Update existing code
- Run CLI commands
- Git operations

## DO NOT
- ❌ Run tests
- ❌ Write test files
- ❌ Explain theory
- ❌ Suggest without implementing
